# nithurshen.github.io

Source for my personal academic website: **https://nithurshen.github.io**

A single static page (plain HTML and CSS, no build step), hosted on GitHub Pages.

## Structure

- `index.html`: the page content
- `style.css`: styles (light/dark, responsive)
- `files/`: CV and résumé PDFs
- `media/`: profile photo

## Local preview

Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.
